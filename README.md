## 🃏 1. 銀魂：萬事屋大亂鬥（戰術卡牌遊戲）

以萬事屋、真選組、攘夷志士／鬼兵隊與歌舞伎町住民為主題的回合制卡牌對戰遊戲，針對筆電寬螢幕設計三欄式免捲動版面。

### ✨ 遊戲特色
- **36 張銀魂角色與惡搞道具卡**：
  - 包含坂田銀時、神樂、志村新八、定春、土方十四郎、沖田總悟、近藤勳、山崎退、桂小太郎、伊莉莎白、高杉晉助、神威、月詠、長谷川泰三 (MADAO)、德川茂茂 (將軍) 等經典角色。
  - 惡搞道具與事件卡：草莓牛奶、特製美乃滋、洞爺湖木刀、Justaway 炸彈、黑暗料理、阿姆斯特朗砲、謎之兵器・愛國者、廁所的砂紙、新八的本體（眼鏡）、將軍的三角內褲、廉價 Cosplay 變裝組。
- **銀魂特色技能**：【白夜叉覺醒】、【嘲諷】、【護盾 🛡️】、【突襲 ⚡】、【亡語】與前列防線【煞車 🛑】控場。
- **隨時補滿 5 張手牌**：開局滿 5 張手牌，出牌後自動補滿 5 張（牌庫抽乾時判負）。
- **8 大原作關卡 ＋ 隱藏關卡 ＋ 無盡挑戰賽**：
  - 擊敗第 8 關後解鎖隱藏關卡 **「終焉與救贖（虛＆吉田松陽）」**（我方糖分無限 `∞`，敵方只派出全技能 Boss 虛與吉田松陽）。
  - 擊敗隱藏關卡後可獲得 **「吉田松陽」與「虛 (Utsuro)」** 編入牌組，並開啟 **「🔥 無盡挑戰賽：修羅場」**。

## 🥋 2. 銀魂：街頭大亂鬥（快打旋風風格格鬥）

向《快打旋風 (Street Fighter II)》致敬的 2D 橫向街機對打遊戲，支援 **1P vs 電腦 AI** 與 **1P vs 2P 雙人同機對戰**（三戰兩勝制）。

### ✨ 遊戲特色
- **6 位可選銀魂格鬥家**：坂田銀時、神樂、土方十四郎、沖田總悟、桂小太郎、高杉晉助，各自擁有專屬造型、武器、必殺技與超必殺技。
- **3 大對戰舞台**：歌舞伎町夜晚、恆道館道場、江戶城天守。
- **街機格鬥系統**：雙層延遲扣血條、打擊停頓 (Hitstop)、畫面震動、格擋防禦 (`GUARD!`)、輕重攻取消連段 (`HITS!`) 與集滿 100% 氣力的超必殺技。

### 🎮 操作按鍵
- **1P 操作**：移動 `A / D`（單人模式亦支援 `← / →`）、跳躍 `W`（或 `↑`）、蹲下防禦 `S`（或 `↓`）、輕攻 `J`、重攻 `K`、必殺技 `L`、超必殺 `U`（滿氣時）。
- **2P 操作（雙人模式）**：移動跳蹲 `← → ↑ ↓`、攻擊鍵 `1 / 2 / 3 / 4`（小鍵盤或 `, . / ;`）。
